# Food Delivery Data Analysis Hackathon

## Objective
To integrate transactional, user, and restaurant data from CSV, JSON,
and SQL formats into a single unified dataset and perform data analysis
to extract meaningful business insights.

## Files in Repository
- Food_Delivery_Analysis.ipynb – Main Jupyter Notebook
- final_food_delivery_dataset.csv – Final merged dataset (source of truth)
- orders.csv – Transactional data
- users.json – User master data
- restaurants.sql – Restaurant master data

## Key Steps
1. Loaded CSV, JSON, and SQL data sources
2. Performed LEFT JOINs using user_id and restaurant_id
3. Created a unified dataset
4. Conducted exploratory data analysis

## Tools Used
- Python
- Pandas
- SQLite
- Matplotlib

## How to Run
1. Clone the repository
2. Open Food_Delivery_Analysis.ipynb
3. Run all cells
